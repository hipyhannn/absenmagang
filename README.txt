LOGBOOK MAGANGHUB - cara pasang di GitHub Pages

1. Ekstrak zip ini dulu (GitHub tidak mengekstrak zip sendiri).
2. Buka repo di GitHub > Add file > Upload files.
3. Seret SEMUA file hasil ekstrak (bukan file zip-nya) ke halaman itu:
   index.html, logbook.webmanifest, logbook-sw.js, logbook-icon-192.png, logbook-icon-512.png
4. Klik Commit changes.
5. Settings > Pages > Deploy from a branch > main > / (root) > Save.
6. Tunggu 1-2 menit, buka https://NAMA-GITHUB.github.io/NAMA-REPO/
7. Di HP: menu browser > Tambahkan ke layar utama.

AI (opsional): buka bagian "Pengaturan AI" di halaman, isi kunci API Gemini dan nama model, lalu Tes koneksi.
Kunci tersimpan di browser saja. Jangan menulisnya di file atau repo.
Tanpa kunci, aplikasi memakai template cadangan.

Catatan: jika repo sudah punya index.html lama, file itu akan tertimpa.
